# 데코레이터 중첩 적용 순서 확인

두 데코레이터를 한 함수에 겹쳐 적용했을 때 어느 쪽이 먼저 함수를 감싸는지 호출 로그로 비교한다.

```python
@outer
@inner
def work(): ...
```

위 코드에서 `inner`가 먼저 `work`를 감싸고, `outer`가 그 결과를 한 번 더 감싼다. 실행 로그를 보면 `outer` 래퍼가 가장 먼저 진입하고 가장 나중에 빠져나온다.

코드는 `src/stacking_order.py` 한 파일이다. 데코레이터 정의를 먼저 읽고, 마지막의 `work()` 호출 로그를 순서대로 따라가면 된다.
