# ExitStack 부분 획득 실패 시 역순 롤백과 pop_all() 소유권 이전

contextlib.ExitStack을 사용하여 동적 개수의 리소스를 획득할 때, 중간에 실패하면 이미 획득한 리소스들이 역순(LIFO)으로 해제되는지 확인한다. pop_all()을 통한 소유권 이전, 정리 콜백 예외 시 예외 체이닝과 나머지 콜백 실행, 그리고 빈 입력(리소스 0개) 경계 사례도 함께 다룬다.

실행 방법: `python3 src/exitstack_partial_acquire.py`

테스트하는 상황:
- N개 리소스 중 중간에 획득 실패 시 이미 획득한 리소스들이 역순(LIFO)으로 해제되고 원래 예외가 전파된다
- pop_all()로 소유권을 이전하면 팩토리 함수는 리소스를 닫지 않고 호출자가 나중에 반환된 스택을 닫는다 (성공 시나리오)
- 팩토리 함수 내부에서 리소스 획득 실패 시 지금까지 획득한 모든 리소스를 역순으로 해제하고 예외를 전파하며 스택을 반환하지 않는다 (올-오어-낫싱 실패 시나리오)
- with 본문에서 예외가 발생하고 정리 콜백도 예외를 발생시키면 콜백 예외가 최종 예외가 되고 본문 예외는 __context__로 체이닝되며 나머지 모든 콜백과 리소스가 LIFO 순서로 정리된다
- 빈 입력(리소스 0개)에서도 정상 작동하고 아무 리소스도 닫지 않는다
- ExitStack을 직접 사용할 때 리소스를 추가하지 않아도 정상 작동한다
