# key 함수와 sort 안정성 확인

이 폴더는 sorted()와 list.sort()에서 key 함수가 같은 값을 돌려줄 때 원래 삽입 순서가 유지되는지 확인한다.

입력은 (이름, 점수, 입력 순서) 튜플 목록이다. 점수가 같은 항목이 여러 개 있도록 만들었다.

확인 방법은 세 가지다.

1. 점수만 key로 쓴다. 점수가 같은 항목끼리는 입력 순서가 그대로 남는지 본다.
2. (점수, 이름) 복합 key를 쓴다. 이름이 우선순위가 되면서 입력 순서가 바뀌는 지점을 본다.
3. reverse=True를 쓴다. 역순 정렬에서도 같은 값끼리의 상대 순서가 어떻게 되는지 본다.

각 결과는 입력 순서 번호와 함께 출력된다. 번호가 증가하는 구간이면 안정성이 유지된 것이고, 감소하는 구간이면 key가 순서를 바꾼 것이다.

실행은 표준 라이브러리만 사용한다. 파일은 src/stable_sort_key_order.py 하나다.
